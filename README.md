# Exemplo Do While

## Descrição

O programa utiliza a estrutura de repetição `do while` para imprimir os valores da variável `i`, começando em 0 e indo até 4.

A cada repetição, o valor de `i` é exibido e, em seguida, incrementado em 1.

## Tecnologias utilizadas

- Java
- NetBeans
- Maven

## Entrada

Este programa não possui entrada de dados.

## Saída

O programa imprime os valores de `i` de 0 até 4.
